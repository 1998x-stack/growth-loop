# Contributing to Growth Loop

Thank you for improving a skill that values **evidence, clear decisions, and real-world feedback**.

## Scope
Accept changes that clarify skill routing, reduce hallucinations, improve practical experiments, document reproducible failure cases, improve accessibility, or update reputable references.

## Standards
- Preserve the **three horizons / three outcomes / three questions**.
- Distinguish research findings from framework heuristics and personal interpretations.
- Link scholarly sources with DOI or a stable institutional URL. State important boundaries.
- Include an example and/or an evaluation scenario for behavioral changes.
- Avoid collecting user data, diagnosing mental health, encouraging dangerous overwork, or asserting guaranteed growth.
- Keep the one-prompt installer safe, transparent and reversible.
- SVG diagrams must have title/description, readable contrast, and contain no external scripts or assets.

## Validation
Run: python3 scripts/validate.py

Issues and pull requests are welcome. Include your agent/platform, the behavior you expected, the behavior observed, and a reproducible minimal example. Do not share private user data.
